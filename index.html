Voice commands

Numbers can be spoken or mixed with words — “one twenty” = 120, “forty five” = 45.

  • Play / Stop — “go”, “start”, “stop”
  • Set tempo — say a number, e.g. “one hundred twenty”
  • Tempo by name — “presto”, “andante”, “안단테”, “프레스토”… (matched even if slightly mis-heard, e.g. “모델아트” → Moderato)
  • Faster / Slower — “faster”, “slower”
  • Time signature — “three four”, “6/8”, “8분의 6박자”, “waltz”
  • Subdivision — “subdivision 2”, “세분박 3”
  • Tap — “tap”
  • Speed ramp — “50 to 150 by 10 every 30”, “50부터 시작해서 150까지 10씩 30초마다”, or by name “안단테부터 프레스토까지 10씩 올려줘”. “stop” ends it.
  • Adjust a running ramp — re-state just one part: “every 7 seconds”, “매 7초만”, “8씩”, “200까지”
  • Restart from a new start — “50부터 다시 시작해줘” (keeps the same target/step)
  • Hold this tempo — “그 템포에서 멈춰줘” (stops climbing, keeps playing)
  • Reset — “reset” (120 BPM, 4/4)
